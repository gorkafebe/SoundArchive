# Design

Design material for Sound Archive's interface. **The interface is not
designed or built yet.** The current page in `web/` is only a system check.

- [UI_RESEARCH_AND_BRIEF.md](UI_RESEARCH_AND_BRIEF.md): research on existing
  sound maps, map and listening patterns, recording and permissions, and
  accessibility, plus the design brief. Done on 2026-11-02.

The design itself is made with the owner in Claude Design: a design system
(colours, type, spacing, components) and a canvas with the screens. It comes
**before** the phase 3 front-end work. When it is done, this folder will also
hold the exported design tokens, screenshots, the component list and a link to
the canvas. The front-end code then reads the tokens as CSS variables.
